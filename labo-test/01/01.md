# Rebonds : simulation d'une balle qui tombe

**Durée**: 90 minutes.
**Rendu**: sur GitHub avant la fin du temps imparti.

## Contexte

On lâche une balle sans vitesse initiale depuis une hauteur `h0`. Elle tombe sous
l'effet de la gravité, rebondit sur le sol en perdant une partie de son énergie,
puis remonte moins haut, et ainsi de suite jusqu'à s'immobiliser.

## Objectifs

- Lire et valider des arguments de la ligne de commande.
- Implémenter une simulation itérative avec une boucle.
- Formater un tableau de résultats.
- Utiliser des constantes (`#define`).

## Théorie

Chute libre avec gravité g = 9.81 m/s² :

    v(t+dt) = v(t) - g * dt
    h(t+dt) = h(t) + v(t+dt) * dt

Lorsque la balle touche le sol (h <= 0), on remet h à 0 et la vitesse est
inversée et atténuée par le coefficient de restitution `e` (0 < e < 1) :

    v = -v * e

La balle est considérée comme arrêtée lorsque, après un rebond, la vitesse est
inférieure à `V_MIN`.

## Constantes

```c
#define G      9.81   // gravité (m/s^2)
#define DT     0.01   // pas de temps (s)
#define V_MIN  0.5    // vitesse de rebond minimale (m/s)
#define T_MAX  60.0   // durée maximale de simulation (s)
```

## Cahier des charges

Le programme reçoit deux arguments :

    ./bounce <hauteur_initiale_m> <coefficient_restitution>

1. Vérifier le nombre d'arguments. Sinon, afficher
   `Usage: ./bounce <hauteur> <restitution>` et retourner 1.
2. Vérifier que la hauteur est > 0 et que le coefficient est dans ]0 ; 1[.
   Sinon, afficher `[ERROR] Invalid parameter` et retourner 1.
3. Implémenter les fonctions suivantes (prototypes imposés) :

```c
// Fait avancer la balle d'un pas de temps. Modifie la hauteur et la vitesse
// via les pointeurs.
void step(double *height, double *speed);

// Gère le rebond si la balle touche le sol. Retourne 1 s'il y a eu rebond, 0 sinon.
int bounce(double *height, double *speed, double restitution);

// Affiche une ligne du tableau de suivi.
void print_line(double time, double height, double speed, int bounces);
```

4. Dans `main`, simuler jusqu'à ce que la balle s'arrête (vitesse de rebond
   < `V_MIN`) ou que `T_MAX` soit atteint.
5. Afficher une ligne de suivi à chaque rebond.
6. Afficher le rapport final : nombre de rebonds, temps total, hauteur maximale
   atteinte après le premier rebond.

## Exemple
